# 画面遷移図

## 概要

利用者向け画面と運転手向け画面の遷移を示す。予約状態と便の状態は、要件定義書の状態定義に合わせている。

1つのアカウントで利用者・運転手の両方を登録できるが、表示されるのは稼働中の区分の画面だけとする。区分は共通の切り替え画面から変更する。

## 全体遷移

```mermaid
flowchart TD
    TOP[トップ画面]
    SW[アカウント・稼働区分切り替え画面]

    subgraph Rider[利用者]
        R1[乗車予約画面]
        R2[予約確認画面]
        R3[予約完了画面]
        R8[配車候補選択画面]
        R4[予約詳細・キャンセル画面]
        R5[予約履歴画面]
        R6[予約キャンセル完了]
        R7[予約確定詳細]
    end

    subgraph Driver[運転手]
        D1[運転手ホーム・担当運行一覧]
        D2[運行詳細・状態更新画面]
        D3[運行履歴画面]
    end

    TOP --> SW
    SW -->|利用者として稼働| R1
    SW -->|運転手として稼働| D1
    SW -.->|未完了の予約・運行あり| SW

    R1 -->|入力内容を確認| R2
    R2 -->|予約登録| R3
    R2 -->|修正| R1
    R3 -->|候補を表示| R8
    R8 -->|候補を選んで確定| R7
    R8 -->|候補なし・条件変更| R1
    R4 -->|matching| R8
    R4 -->|予約確定後| R7
    R4 -->|キャンセル| R6
    R5 -->|予約を選択| R4
    R6 --> R5

    D1 -->|便を選択| D2
    D2 -->|運行開始・乗車完了| D1
    D1 --> D3

    R8 -.->|確定を通知| D1
    D2 -.->|運行中・乗車完了を反映| R7
    R4 -.->|キャンセルを反映| D2
```

## 利用者向け詳細

```mermaid
stateDiagram-v2
    [*] --> 乗車予約画面
    乗車予約画面 --> 予約確認画面: 必須項目を入力
    乗車予約画面 --> 乗車予約画面: 入力エラーを表示
    予約確認画面 --> 乗車予約画面: 内容を修正
    予約確認画面 --> 予約完了画面: 予約を登録
    予約完了画面 --> 配車候補選択画面: 候補を表示
    配車候補選択画面 --> 選択確認: 候補を選ぶ
    選択確認 --> 予約確定詳細: 配車を確定
    選択確認 --> 配車候補選択画面: 戻る
    配車候補選択画面 --> 乗車予約画面: 候補なし・条件を変更
    予約詳細画面 --> 配車候補選択画面: matching
    予約詳細画面 --> 予約確定詳細: confirmed・in_progress
    予約詳細画面 --> 予約履歴画面: completedまたはcancelled
    予約詳細画面 --> キャンセル確認: キャンセル
    キャンセル確認 --> キャンセル完了: キャンセルを実行
    キャンセル確認 --> 予約詳細画面: 戻る
    キャンセル完了 --> 予約履歴画面
    予約履歴画面 --> 予約詳細画面: 予約を選択
```

## 運転手向け詳細

```mermaid
flowchart TD
    A[運転手ホーム・担当運行一覧] -->|便を選択| B[運行詳細]
    B -->|confirmed| C{運行開始を確認}
    C -->|記録する| D[運行中]
    C -->|戻る| B
    D --> E{乗車完了を確認}
    E -->|記録する| F[乗車完了]
    E -->|戻る| D
    F --> A
    A --> G[運行履歴]
    G -->|便を選択| B
```

## 遷移ルール

| 遷移元 | 操作・条件 | 遷移先 |
| --- | --- | --- |
| 稼働区分切り替え画面 | 登録済みの区分を選ぶ | その区分のホーム画面 |
| 稼働区分切り替え画面 | 未完了の予約・運行がある | 同じ画面で理由を表示 |
| 乗車予約画面 | 必須項目が正しい | 予約確認画面 |
| 乗車予約画面 | 必須項目不足・形式不正 | 同じ画面でエラー表示 |
| 予約確認画面 | 予約登録 | 予約完了画面（`matching` 状態） |
| 予約完了画面 | 候補作成済み | 配車候補選択画面 |
| 配車候補選択画面 | 候補を選んで確定 | 予約確定詳細（`confirmed` 状態） |
| 配車候補選択画面 | 候補なし | 条件変更の案内、または乗車予約画面 |
| 運行詳細画面 | 運行開始 | `in_progress` 状態 |
| 運行詳細画面 | 乗車完了 | `completed` 状態 |
| 予約詳細画面 | 利用者がキャンセル | `cancelled` 状態 |
