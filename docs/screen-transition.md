# 画面遷移図

## 概要

利用者向け画面と配車担当者向け画面の遷移を示す。予約状態は、要件定義書の状態定義に合わせている。

## 全体遷移

```mermaid
flowchart TD
    TOP[トップ画面]

    subgraph Rider[利用者]
        R1[乗車予約画面]
        R2[予約確認画面]
        R3[予約完了・マッチング結果画面]
        R4[予約詳細・キャンセル画面]
        R5[予約履歴画面]
        R6[予約キャンセル完了]
        R7[予約確定詳細]
    end

    subgraph Dispatcher[配車担当者]
        D1[配車ダッシュボード]
        D2[予約一覧画面]
        D3[AI配車候補確認画面]
        D4[ルート・乗車順編集画面]
        D5[配車詳細・運行状態更新画面]
        D6[手動配車画面]
    end

    TOP --> R1
    TOP --> R5
    TOP --> D1

    R1 -->|入力内容を確認| R2
    R2 -->|予約登録| R3
    R2 -->|修正| R1
    R3 -->|予約番号を表示| R4
    R3 -->|マッチング中| R4
    R4 -->|予約確定後| R7
    R4 -->|キャンセル| R6
    R5 -->|予約を選択| R4
    R6 --> R5

    D1 --> D2
    D2 -->|予約を選択| D3
    D3 -->|候補を確認| D4
    D3 -->|候補なし・AI失敗| D6
    D4 -->|乗車順・出発時刻を修正| D5
    D4 -->|候補を確定| D5
    D6 -->|手動配車を確定| D5
    D5 -->|状態更新| D2

    D5 -.->|確定・変更を通知| R7
    D5 -.->|キャンセル状態を反映| R6
```

## 利用者向け詳細

```mermaid
stateDiagram-v2
    [*] --> 乗車予約画面
    乗車予約画面 --> 予約確認画面: 必須項目を入力
    乗車予約画面 --> 乗車予約画面: 入力エラーを表示
    予約確認画面 --> 乗車予約画面: 内容を修正
    予約確認画面 --> 予約完了画面: 予約を登録
    予約完了画面 --> 予約詳細画面: 予約番号を確認
    予約詳細画面 --> 予約詳細画面: matching
    予約詳細画面 --> 予約確定詳細: confirmed
    予約詳細画面 --> 予約履歴画面: completedまたはcancelled
    予約詳細画面 --> キャンセル確認: キャンセル
    キャンセル確認 --> キャンセル完了: キャンセルを実行
    キャンセル確認 --> 予約詳細画面: 戻る
    キャンセル完了 --> 予約履歴画面
    予約履歴画面 --> 予約詳細画面: 予約を選択
```

## 配車担当者向け詳細

```mermaid
flowchart TD
    A[配車ダッシュボード] --> B[予約一覧]
    B -->|日付・時間帯・状態で絞り込み| B
    B --> C[予約詳細]
    C --> D[AI配車候補確認]
    D -->|条件を満たす候補あり| E[ルート・乗車順編集]
    D -->|候補なしまたはAI処理失敗| F[手動配車]
    E -->|利用者を外す| D
    E -->|乗車順・降車順・出発時刻を修正| E
    E -->|配車を確定| G[配車詳細・運行状態更新]
    F -->|グループ・車両・順序を設定| G
    G -->|確認待ち| B
    G -->|配車確定| B
    G -->|運行中| B
    G -->|乗車完了| B
    G -->|キャンセル| B
```

## 遷移ルール

| 遷移元 | 操作・条件 | 遷移先 |
| --- | --- | --- |
| 乗車予約画面 | 必須項目が正しい | 予約確認画面 |
| 乗車予約画面 | 必須項目不足・形式不正 | 同じ画面でエラー表示 |
| 予約確認画面 | 予約登録 | 予約完了・マッチング結果画面 |
| 予約完了画面 | 登録直後 | `matching` 状態 |
| AI配車候補確認画面 | 候補を確認 | ルート・乗車順編集画面 |
| AI配車候補確認画面 | 候補なし・AI利用不可 | 手動配車画面 |
| ルート・乗車順編集画面 | 配車確定 | `confirmed` 状態 |
| 配車詳細画面 | 運行開始 | `in_progress` 状態 |
| 配車詳細画面 | 運行完了 | `completed` 状態 |
| 利用者・担当者 | キャンセル | `cancelled` 状態 |
